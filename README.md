🛒 ModernShop – E-Commerce Website










A modern front-end e-commerce demo website built using HTML, CSS, and Vanilla JavaScript.
The project demonstrates a simple online shopping interface with product display, navigation system, and a dynamic cart counter.



📌 Project Overview

ModernShop is a beginner-friendly front-end e-commerce project designed to demonstrate key web development concepts such as:

Responsive layout design

DOM manipulation using JavaScript

Product listing interface

Shopping cart interaction

Clean and modern UI structure

This project is suitable for web development practice, portfolios, and learning JavaScript fundamentals.

✨ Features

✔ Responsive navigation bar
✔ Interactive product listing
✔ Add-to-cart functionality
✔ Cart item counter update
✔ Clean and modern UI design
✔ Multi-section page navigation
